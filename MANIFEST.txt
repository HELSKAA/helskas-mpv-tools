Helska's MPV Tools — MANIFEST
========================
Windows-only self-contained build. All paths relative to this file.

This is the DEFAULT pack. It ships 8 Lua modules (the Console + 7 features).
The optional "hold-to-speed" and "rebind mouse 4/5 to arrows" helpers are
intentionally NOT included; the loader auto-discovers *.lua files, so you can
drop either one into helska/ later and it will simply load.

MODULES (Lua)
-------------
helska.lua                              loader (auto-discovers helska/*.lua)
helska/helska_console.lua               Console menu (TAB)
helska/helska_audio-clipboard.lua       audio -> clipboard (FFmpeg)
helska/helska_chinese.lua               tone colours + Hanzi conversion
helska/helska_extract-current-subtitle.lua  save / preload a subtitle track
helska/helska_playback.lua              next / previous video
helska/helska_screenshot-clipboard.lua  frame (with/without subs) -> clipboard
helska/helska_subtitle-font.lua         subtitle font picker
helska/helska_subtitle_clipboard.lua    subtitle text -> clipboard
helska/helska_tone_colors.py            helper used by helska_chinese.lua

SHARED FOLDER
-------------
helska/temporary_files/README.txt       self-cleaning scratch folder (see
                                        FEATURES.txt). Features write their
                                        short-lived working files here and
                                        delete them automatically; generated
                                        files are never committed.

NOTE: helska/ffmpeg/ffmpeg.exe is NOT stored in the git repository - it is
larger than GitHub's 100 MiB per-file limit. It is included in the release
.zip; see helska/ffmpeg/README.txt.
