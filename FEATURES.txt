========================================================================
  HELSKA'S MPV TOOLS  -  feature guide
========================================================================

An mpv script bundle for Windows. Each script does one job; together they
share a small in-player menu called the Console (TAB). Everything the scripts
need (FFmpeg, OpenCC, portable Python) is bundled.

INSTALL
-------
1. Copy helska.lua and the helska/ folder into mpv's scripts/ folder:
       Windows  %APPDATA%\mpv\scripts\
       macOS    ~/.config/mpv/scripts/
       Linux    ~/.config/mpv/scripts/
2. Restart mpv.

First launch clears Windows' "downloaded from the internet" flag on the bundled
tools, so you should not see a SmartScreen prompt. To uninstall, delete
helska.lua and the helska/ folder.

REQUIREMENTS
------------
* Windows for the bundled tools. The Lua features also run on macOS/Linux,
  using a system Python + pypinyin and FFmpeg/OpenCC from PATH.
* mpv 0.41.0 (tested). The Subtitle clipboard feature needs mpv's built-in
  clipboard/text property.

KEYS
----
  TAB ............. open the Console (menu of everything)
  Ctrl+E .......... copy the current subtitle's audio to the clipboard
  Ctrl+Shift+E .... manual audio clip (1st press = start, 2nd = end)
  Alt+E ........... audio-boost menu (gain for extracted clips)
  Ctrl+T .......... toggle tone-coloured subtitles
  Ctrl+Alt+C ...... toggle Simplified <-> Traditional
  Alt+T ........... tone-colour palette editor
  Ctrl+Shift+X .... save the current subtitle track to a file
  Ctrl+. / Ctrl+, . next / previous video in the folder
  Ctrl+S .......... copy a frame with subtitles
  Ctrl+Shift+S .... copy a frame without subtitles
  Ctrl+J .......... subtitle font / size picker
  Ctrl+C .......... copy the current subtitle text
  Ctrl+A .......... toggle auto-copy of every subtitle

Every key can be changed in the Console, or in helska/helska.conf (created the
first time you change a binding or tone setting).

THE CONSOLE (TAB)
-----------------
A menu of every action, and where you manage keys without editing files.

  TAB ............ open / close
  type ........... filter the list
  Up / Down ...... move the highlight
  ENTER .......... run the highlighted action
  ESC ............ close

It also accepts a few commands typed into its input line:
  bind <command> <key>     e.g.  bind tones Ctrl+t
  unbind <command>
  unbind all
  defaultbind <command>
  defaultbind all

Changes are written to helska/helska.conf and applied immediately.

FEATURES
--------
Audio -> clipboard (needs FFmpeg)
  Ctrl+E        cut the audio of the subtitle on screen to an MP3 on the
                clipboard.
  Ctrl+Shift+E  manual clip: 1st press = start, 2nd = end. While selecting:
                Left/Right = 0.1s, Shift+Left/Right = 0.5s, Ctrl+Left/Right =
                nearest subtitle start, Alt+Left/Right = nearest end, Esc =
                cancel.
  Alt+E         audio-boost menu; affects extracted clips only, never playback.

Chinese (tone colours + Hanzi conversion)
  Works on the selected subtitle track and never changes your original file -
  it builds a temporary generated track beside it.
  Ctrl+T        tone-colour each syllable (via pypinyin).
  Ctrl+Alt+C    convert Simplified <-> Traditional (direction auto-detected).
  Alt+T         tone-colour palette editor; paste a #RRGGBB code per tone.
  The two can be used together and rebuild cleanly from the original.

Extract subtitle
  Ctrl+Shift+X  save the selected subtitle track to a file beside the video.
  preload-subs  same, but loads a temporary track instead of saving. Unbound
                by default; use  bind preload-subs <key>  to give it a key.

Playback
  Ctrl+. / Ctrl+,   next / previous video in the folder, naturally sorted.

Screenshot -> clipboard
  Ctrl+S / Ctrl+Shift+S   copy the current frame with / without subtitles.
  No FFmpeg needed.

Subtitle font / size (Ctrl+J)
  Type to filter, arrows to move, ENTER to audition, Ctrl+V to paste a name.
  Changes apply immediately; save to keep them in helska.conf.

Subtitle -> clipboard
  Ctrl+C   copy the subtitle text on screen.  Ctrl+A   auto-copy each new one.
  Uses mpv's built-in text clipboard.

TEMPORARY FILES  (helska/temporary_files)
------------------------------------------
Features write short-lived working files here instead of scattering them
around your system, and remove them automatically:

  * Screenshots: written, copied, deleted immediately (the clipboard holds the
    image data, so pasting still works).
  * Audio clips: kept only until the clipboard stops pointing at them, so you
    can still paste the file.
  * Chinese tone-colour / conversion and preload files: removed when the track
    is switched off or mpv closes.

Only files inside this folder (never the README) are ever deleted. Files keep
their normal names, e.g. an audio clip is "<video>_<start>-<end>_<hash>.mp3".
A ".helska-session-<pid>" marker lets a second mpv window leave the first
window's files alone. If mpv is force-quit before cleanup, leftovers are
removed on the next launch.

ADDING / REMOVING FEATURES
--------------------------
The loader runs every *.lua inside helska/. Delete a file to remove a feature;
drop one in to add it. A script can join the Console by implementing the small
message protocol described at the top of helska_console.lua. There is no list
to edit.

TROUBLESHOOTING
---------------
  * A key does nothing: another script may own it, or you deleted that module.
    Check that the Console (TAB) still lists the action.
  * Chinese features do nothing: make sure a subtitle track is selected.
  * See the loader's messages: start mpv from a terminal and look for the line
    beginning "helska loader:".
  * Windows complains about a bundled .exe: restart mpv once; the loader
    unblocks the tools on first run.
